# Cambios incluidos

- Backend local Node.js en la raíz, sin alterar el backend .NET existente.
- Persistencia atómica en JSON entre reinicios y recompilaciones.
- Autenticación común para OCC, Gestión Humana, Contratos, Finanzas y agente móvil.
- Flujo integrado: solicitud, revisión, contrato, personal, asignación, operación, aprobación y pre-facturación.
- Centro de flujo accesible desde las cuatro áreas mediante el botón naranja **Flujo integrado**.
- Chat persistente entre departamentos y chat móvil agente–OCC.
- Sincronización móvil real, conservando la cola cuando el servidor no confirma.
- Envío de solicitudes desde el portal público hacia Contratos.
- Exportación consolidada a PDF y Excel.
- Semilla demostrativa con `B6 1015` asignado al agente móvil.

## Alcance del prototipo

Las acciones críticas del recorrido completo usan el backend persistente. Algunas vistas secundarias heredadas continúan mostrando sus datos de demostración originales; el Centro de flujo ofrece la ruta verificable y compartida para la presentación del proceso integral.
