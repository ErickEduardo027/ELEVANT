# ELEVANT public-web assets

- `brand/`: ELEVANT identity supplied by the project team.
- `generated/`: visual material created for the authorized local ELEVANT presentation and reused for this landing page.
- `earth/`: NASA Visible Earth textures; see `earth/README.md` for sources and credit.
- `fonts/`: Bricolage Grotesque and DM Mono, distributed under the SIL Open Font License included beside the files.
- `3d/`: lightweight original procedural geometry used by the interactive hero; no third-party model is required at runtime.

All runtime assets are local. The landing page makes no media request to a third-party host.
