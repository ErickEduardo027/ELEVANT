# Airline icons

These small brand icons were fetched from the airlines' own public favicon endpoints on 2026-09-27 and converted to PNG without altering the artwork. They identify the airline in the historical AVIAM selector; they do not verify its legal entity. The trademarks belong to their respective owners.

| File | Source |
| --- | --- |
| `aerolineas-argentinas.png` | https://www.aerolineas.com.ar/favicon.ico |
| `air-canada.png` | https://www.aircanada.com/favicon.ico |
| `american-airlines.png` | https://www.aa.com/favicon.ico |
| `avianca.png` | https://www.avianca.com/favicon.ico |
| `british-airways.png` | https://www.britishairways.com/favicon.ico |

The same files and paths are present in AVIAM Web so both clients display the catalog consistently. Airlines without a reviewed icon use a monogram.
