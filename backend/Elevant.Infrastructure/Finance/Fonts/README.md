# Bundled PDF typeface

`NotoSans-Regular.ttf` is the unmodified Noto Sans font from
[`notofonts/noto-fonts`](https://github.com/notofonts/noto-fonts/blob/ffebf8c1ee449e544955a7e813c54f9b73848eac/hinted/ttf/NotoSans/NotoSans-Regular.ttf),
commit `ffebf8c1ee449e544955a7e813c54f9b73848eac`. Its license is [OFL.txt](OFL.txt).
This embedded typeface makes PDF generation independent of fonts installed on
the API host. It is not a user-uploaded asset.
