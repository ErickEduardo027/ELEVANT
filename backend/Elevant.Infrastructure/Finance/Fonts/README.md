# Bundled PDF typeface

`NotoSans-Regular.ttf` and `NotoSans-Bold.ttf` are the unmodified Noto Sans fonts from
[`notofonts/noto-fonts`](https://github.com/notofonts/noto-fonts/tree/ffebf8c1ee449e544955a7e813c54f9b73848eac/hinted/ttf/NotoSans),
commit `ffebf8c1ee449e544955a7e813c54f9b73848eac`. Their license is [OFL.txt](OFL.txt).
These embedded typefaces make PDF generation independent of fonts installed on
the API host. They are not user-uploaded assets.
