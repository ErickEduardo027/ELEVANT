# Public airline registries

Used by `POST governance/airlines/{id}/registry-check` (ADR-0023).

- **Wikidata** (`WikidataAirlineRegistrySource`): live SPARQL query to
  `query.wikidata.org` by IATA (P229) or ICAO (P230). Wikidata data is CC0; no key
  is needed. The request sends an identifying `User-Agent`, as the Wikimedia
  policy requires.
- **OpenFlights** (`openflights-airlines.tsv`): offline copy used when Wikidata
  does not answer. It is generated by
  `scripts/data/generate-openflights-airlines.mjs` from `airlines.dat` at commit
  `5d623a6969a1adee7961cf1c9a8a212c4a784713` of
  [jpatokal/openflights](https://github.com/jpatokal/openflights), with the source
  file checked by SHA-256. Do not edit the TSV by hand.

  The airline data comes from [OpenFlights](https://openflights.org/data) and is
  made available under the
  [Open Database License (ODbL) 1.0](https://opendatacommons.org/licenses/odbl/1-0/).
  The derived TSV keeps that license.
